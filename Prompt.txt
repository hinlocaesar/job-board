# GOAL
We are building a remote-work job marketplace in the style of OnlineJobs.ph, connecting
Philippine-based remote workers with employers worldwide. Follow AGENTS.md.

# ARCHITECTURE (do not deviate without asking)
- **Umbraco (headless, Content Delivery API)**: marketing/editorial content only: homepage,
  blog, SEO landing pages, FAQ/help center, category descriptions.
- **Marketplace API**: separate ASP.NET Core project in the same solution, PostgreSQL via EF Core,
  ASP.NET Identity + JWT. Owns users, profiles, jobs, applications, subscriptions.
- **Frontend**: `<Nuxt 3 | Vue 3 + Vite>` + TypeScript, consuming both APIs. Public job and
  profile pages must be SEO-friendly (SSR/prerender).
- Use official MCP/tools first (Umbraco Developer MCP for the CMS side, dev instance only).

# PHASE 1: MVP ONLY (build this, nothing more)
1. Auth: register/login as Employer or Worker, email verification, password reset.
2. Worker profile: headline, skills, experience, expected rate, availability, resume upload
   (blob storage, size/type validated), public/private toggle.
3. Employer: post a job (title, category, description, type, pay range), edit/close it.
4. Public job board: list, search, filter by category/type/pay, pagination, job detail page.
5. Apply flow: worker applies to a job, employer sees applicants and can shortlist/reject.
6. Umbraco: homepage, blog list/post, one landing-page template, FAQ. Delivered via the Delivery API.
7. Basic admin moderation: approve/flag jobs, ban users.

# OUT OF SCOPE FOR NOW
Payments/subscriptions, in-app messaging, notifications beyond email, mobile app.
Design the data model so they can be added later, but don't build them.

# NON-FUNCTIONAL
- Rate limiting and input validation on all public endpoints. Server-side authorization checks.
- Personal data handling compliant in spirit with the PH Data Privacy Act: consent on signup,
  account deletion/export, contact details of workers hidden from unauthenticated users.
- Full-text search in Postgres for now, behind an interface so it can be swapped later.
